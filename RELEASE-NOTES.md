**One library for every PC game.** Lumen finds what you already own across Steam, Epic, GOG, EA, Ubisoft, Xbox, Battle.net, Amazon and Quiver, plus any game you point it at yourself, and launches each one through its own launcher. It has a desktop view and a Big Screen mode built for a TV and a controller.

### Which file to take

| | |
|---|---|
| **Lumen Setup 0.1.0.exe** | The installer. Asks where to put it and makes the shortcuts. Take this one if you are not sure. |
| **Lumen 0.1.0.exe** | Portable, one file, nothing installed. Good for a USB stick. |
| **Lumen-win.zip** | The same program as a folder. Unzip it and run `Lumen.exe` inside. |

Windows 10 or 11, 64-bit. Nothing else to install.

### "Windows protected your PC"

You will see that blue box the first time. It appears because this build is not signed with a paid certificate, not because anything is wrong with it. Click **More info** and then **Run anyway**. With the zip, right-click it before you unzip, choose **Properties**, tick **Unblock**, and the warning does not come back.

### What is in it

- Your whole library in one place, with artwork, favourites, recently played and how long you have played each game.
- **Big Screen**: a full-screen mode for the sofa, driven entirely by a controller, with its own menu, search keyboard and screensaver.
- **Controller first** everywhere: rebindable buttons, stick navigation that goes where you expect, and the pad working as a mouse when a launcher window wants an answer.
- **Installs and uninstalls from inside Lumen**, with live progress, and a way straight into a launcher's own download list when something is stuck in its queue.
- **What is happening**: gaming headlines, Steam's new releases and its live most-played chart, the weather, deals and your achievements.
- **Your PC at a glance**: drive space, temperatures, and a controller's battery where Windows reports one.
- Twelve languages, eight tile styles, themes, wallpapers and music written for it.

### Known limits

- Windows only.
- Unsigned, so the SmartScreen box above.
- Temperatures come from what Windows itself can answer, which on most desktops is the graphics card and the drives. A per-core CPU and a motherboard reading need a driver Windows does not offer.
- A controller's battery only shows when Windows knows it, which in practice means a pad paired over Bluetooth.
